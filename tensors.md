Tensors
A tensor is a specialized multi-dimensional array designed for mathematical and computational efficiency.

Examples of Tensors
1. Scalar → A single number
2. Vector → A 1D array of numbers
3. Matrix → A 2D grid of numbers
4. 3D Tensor → Colored images (RGB images)
5. 4D Tensor → Batches of RGB images
6. 5D Tensor → Video data

   
Why Tensors are Useful?
Tensors are widely used because they support:
1. Efficient mathematical operations
2. Representation of real-world data
3. High-performance computations


Tensors in Deep Learning
In deep learning, tensors are used for:
1. Data storage
2. Weights and biases
3. Matrix operations
4. Model training processes


Tensor Properties
When working with tensors in libraries like PyTorch or TensorFlow, three important properties define a tensor:
1. Shape- 
A tuple that specifies the number of elements along each axis.
2. Data Type (dtype)- 
Defines the type of data stored in the tensor, such as integers or floating-point numbers.
3. Device- 
Specifies where the tensor is stored, such as:CPU
